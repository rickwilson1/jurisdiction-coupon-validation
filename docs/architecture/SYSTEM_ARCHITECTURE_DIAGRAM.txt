═══════════════════════════════════════════════════════════════════════════════════
  DATAFLOW
═══════════════════════════════════════════════════════════════════════════════════
  (1) Customer enters coupon + address at shop.agromin.com checkout
  (2) CIMcloud → coupon-validator: ArcGIS geocode + CDTFA district + coupon rules
  (3) On accept, CIMcloud places order and emails sales@agromin.com (subject:
      "Pending Approval for Order Number NNNNNN")
  (4) Power Automate trigger fires on the email; parses fields; POSTs to coupon-
      dispatch with X-API-Key header
  (5) coupon-dispatch writes the order document to Firestore `orders` collection
  (6) coupon-dispatch sends customer-facing email via Microsoft Graph API as
      dispatch@agromin.com; CCs ofelia@; on delivery orders, separately alerts
      greg@, brian@, kendall@
  (7) coupon-dispatch returns structured JSON to Power Automate. For delivery
      orders, PA appends a row to OCWR-Agromin Deliveries.xlsx Table1 via the
      Excel Online connector under rickwilson@'s authentication

═══════════════════════════════════════════════════════════════════════════════════
  ROUTING DECISION (inside coupon-dispatch)
═══════════════════════════════════════════════════════════════════════════════════
   shipping_method == "delivery"              → delivery path
   shipping_method == "pickup":
        qty <  5 cu yd                        → self-load pickup
        qty >= 5 cu yd                        → staff-load pickup
   yard assignment by zip → Oxnard · Camarillo · Dos Palos · Florin Perkins
