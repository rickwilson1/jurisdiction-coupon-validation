  COUPON VALIDATION LOGIC
  ─────────────────────────────────────────────────────────────────────────

  Jurisdiction matching rules                   Date / status checks
  ─────────────────────────────────             ─────────────────────────
  Code type: CITY  → city must match            coupon must exist in list
  Code type: COUNTY→ must be unincorporated     status must be "active"
             county (not inside any city)       start_date ≤ today ≤ end_date
  Match logic: normalize both sides,
               partial-name aware               any failure → 400 with reason
