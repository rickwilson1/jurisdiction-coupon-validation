STEP 5 — Get the Service Principal Object ID
===========================================================

There are two different objects in Entra:
   - "App Registrations"     → the blueprint   → Object ID e507e531-... (NOT what we need)
   - "Enterprise Applications" → the instance  → has its own different Object ID (THIS is what we need)

Get the Service Principal Object ID one of two ways:

  Option A — UI (fastest):
    Microsoft Entra admin center → Enterprise Applications → search "Agromin Coupon Dispatch"
    → click it → copy the Object ID from the Overview page

  Option B — PowerShell:
    Connect-MgGraph -Scopes "Application.Read.All" -NoWelcome
    Get-MgServicePrincipal -Filter "appId eq '8e2401b3-83b0-4edb-9d4e-d72c8de70ab9'" |
        Select-Object Id, DisplayName, AppId

    The "Id" field returned is the Service Principal Object ID.


===========================================================
STEP 6 — Configure RBAC for Applications in Exchange Online
===========================================================

Run this in an Exchange Online PowerShell session (Connect-ExchangeOnline first if not already connected).

REPLACE <SP-OBJECT-ID> with the Service Principal Object ID from Step 5.

# 6a — Register the app as a service principal in Exchange Online
New-ServicePrincipal `
    -AppId "8e2401b3-83b0-4edb-9d4e-d72c8de70ab9" `
    -ServiceId "<SP-OBJECT-ID>" `
    -DisplayName "Agromin Coupon Dispatch"

# 6b — Create a recipient scope restricted to just the dispatch mailbox
New-ManagementScope `
    -Name "CouponDispatchMailboxScope" `
    -RecipientRestrictionFilter "PrimarySmtpAddress -eq 'dispatch@agromin.com'"

# 6c — Assign the Mail.Send role to the app, scoped to that mailbox only
New-ManagementRoleAssignment `
    -App "8e2401b3-83b0-4edb-9d4e-d72c8de70ab9" `
    -Role "Application Mail.Send" `
    -CustomResourceScope "CouponDispatchMailboxScope"

If 6a returns "service principal already exists," skip it and continue with 6b and 6c.
