Validation logic — /api/validate-coupon
1
Coupon lookup — code must exist in loaded dataset
2
Status check — Program Status field must equal Active
3
Date range — today within Start / End Date (open bounds allowed)
4
Geocode address — ArcGIS World Geocoding → lat / lon
5
CDTFA shapefile — point-in-polygon → city + county
6
Jurisdiction match — city coupons require city match; county coupons require unincorporated area
